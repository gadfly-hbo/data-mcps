## 一句话目标

启动 data-mcps 首期开发，交付**可运行的独立产品**：local-first 外部数据集市与采集工作台，贯通「发现 → 评估覆盖/口径/许可 → 连接 → 查询 → 预览与质量检查 → 保存快照 → 明确交付」。

## 产品定位（来自方案.md §01）

- local-first 外部数据集市与采集工作台。让业务用户发现合适的数据，判断是否可用，在授权范围内查询，并保存为带来源、口径、质量和使用限制的数据产物。
- 采用与 metric-factory 一致的方式：业务在独立仓维护，独立可运行，后续以同源固定版本接入 JuanerAI。
- 原型（demo.html）是界面与流程基线；46 项检查只证明原型行为，不能替代正式产品验收。
- 视觉沿用 metric-factory 风格（中性色/绿色 token、230px 侧栏、14px 正文、亮暗主题）。

## 首期范围（用户指令 7 条，逐字要点）

1. **先做独立天气闭环**：数据集市、来源详情、项目连接、查询工作台、质量预览、数据资产、运行记录。
2. **真实产品基础**：本地服务、项目范围、持久存储、快照保存与读回、文件导出。外部数据边界使用明确标注的合成夹具；天气 REST 适配器应有实际实现和可替换的测试接缝。**不停留在前端 localStorage 演示**。
3. **保留 MCP 接入能力**：业务边界区分 MCP 与普通 REST；验证最小 MCP Client 接缝及工具白名单，可用合成 Server 测试。精选来源先行；不开放任意 stdio 命令或自动安装第三方 MCP。
4. **数据与权限可解释**：连接检查和数据验证分开；快照保留来源、参数、范围、单位、时区、采集/更新时间、质量、缺失与使用限制；支持表格和 JSON；快照不可原地覆盖。项目使用权、提取权、导出权、模型外发权分别控制，**默认模型外发关闭**；凭据使用引用，不扫描本机秘密。
5. **落实失败路径**：授权不足、错项目、部分结果、限流、过期缓存、取消、未知结果、工具变化、保存失败、重复操作。费用未知保持未知；失败不推定未计费；未知结果不盲目重试。
6. **品牌画像保留独立合成样板**：明确虚构品牌、平台、观察窗、分母与抑制规则；商业来源待用户授权与正式文档后接入；不承诺个人级画像或绕过许可。
7. **为 JuanerAI 保留最小接缝**：核对现行插件合同（已读：standard.md 五步接入、共用业务分别装配、固定版本交付）；本期不实施宿主接线；不重造分析核心、Agent Runtime、通用插件平台或企业权限系统。

## 方案.md 中的关键业务决策（约束，非开放问题）

- 对象边界：Provider / Connector / MCP Server / Connection / Capability / QueryTemplate / Run / Snapshot / Grant / License（§03）。
- 状态分层：连接状态与运行/保存/交付/费用状态分别显示，禁止「已连接」一徽盖全（§08）。
- 快照不可变：保存 = 写临时 → 校验 → 原子提交 → 独立读回；同一运行重试保存不重复扣费查询；内容不可原地编辑，派生快照保留父链（§07）。
- 质量消费门：完整 = 已知预期 + 实际检查同时满足；13/14 为部分结果，不填零不标完整；关键标识/日期/单位/授权不明为阻断（§07）。
- 参数变化：旧结果标「与当前参数不同」，不能用旧结果保存成新参数产物（§04）。
- 权限四分：提取权、本地快照写入权、导出权、模型外发权分别控制；默认模型外发关闭；撤权阻断新调用，历史保留（§06）。
- 凭据：credential_ref 引用，服务端解析，浏览器不持有长期密钥；系统存储不可用时仅会话内存并明确提示；不降级明文文件（§09）。
- 安全：第三方 MCP 一切输出为不可信输入；工具目录指纹比对，新增/升权工具默认不准入；readOnlyHint 仅提示；UI 白名单必须由服务端同样执行（§09）。
- 天气样板：Open-Meteo Historical Weather REST 为首个真实适配候选；免费 API 限非商业用途，真实调用需另行授权；首期外部数据边界 = 明确标注的合成夹具；原型 14 行全为 synthetic（§10）。
- 画像样板：「青禾生活」虚构品牌、「演示平台」、观察窗 2026-09、分母 1,200、小样本抑制为原型规则；真实来源与合成来源不同身份，不能靠开关伪造（§11）。
- 失败语义：401/403/429/超时/取消/未知/保存失败/工具变化各有用户可见语义与允许的下一步（§08 表）；费用未知 ≠ 0；「演示无调用」≠「供应商免费」。
- 验收定义 A01–A16（§15）为实施应证实的行为。
- 阶段：R0 评审（已完成）→ R1 独立天气闭环（本期）→ R2 商业画像（等授权）→ R3 JuanerAI 固定插件（仅路线）→ R4 扩展（后置）。
